# Local icons

Drop custom `.svg` icons here to use them as `<Icon name="<file-name>" />`
(astro-icon's local collection). The site's icons currently all come from the
Lucide set (`@iconify-json/lucide`, e.g. `lucide:github`).

astro-icon scans this folder on every build and warns if it is missing, so it
is kept even when empty.
